# الانتقال إلى PostgreSQL / Supabase

أُعد المخطط والربط، ونُقلت بيانات المعاينة المحلية إلى PostgreSQL في ٣ نوفمبر ٢٠٢٦: ٨ منتجات، ٠ طلبات. عند تشغيل الموقع بملف `.env.local` الحالي يستخدم قاعدة Supabase؛ ملف `data/farm.json` ما زال محفوظًا كنسخة محلية سابقة.

## تجهيز المشروع

1. أنشئ مشروع Supabase باسم خاص بالمزرعة. احتفظ بكلمة مرور قاعدة البيانات في مدير كلمات المرور. اختر منطقة مناسبة لجمهور الموقع وسياسة بياناته.
2. من **Connect** انسخ URI الخاص بـ **Session pooler** عند تشغيل خادم Next مستمر. اجعله `DATABASE_URL` في `.env.local` أو أسرار الاستضافة، مع `sslmode=verify-full` و`sslrootcert` يشير إلى شهادة `certs/supabase-prod-ca-2021.crt` بمسار صالح لبيئة التشغيل. لا ترسل كلمة المرور في المحادثة أو Git. في الاستضافة serverless استخدم Transaction pooler بدلًا منه، مع مراجعة حجم تجمع الاتصالات.
3. احفظ نسخة من `data/farm.json` ومن `public/media/uploads/`. ملف البيانات المحلي لا يُحذف أثناء النقل.
4. نفّذ `npm run db:check` للمراجعة الجافة. ثم `npm run db:import`. ينشئ الأمر الجداول من `db/001_farm_schema.sql`، ويرفض النقل إذا وجد بيانات في الجداول المستهدفة، ويحفظ نسخة محلية داخل `data/backups/`.
5. بعد تأكيد أعداد المنتجات والطلبات، أعد تشغيل الموقع. يستخدم PostgreSQL عند وجود `DATABASE_URL`. لا تجعل خادمين، أحدهما محلي والآخر متصل بالقاعدة، يستقبلان الطلبات في الوقت نفسه.

## ما الذي أصبح جاهزًا؟

- جداول منفصلة للمنتجات والطلبات وبنود الطلب والإعدادات، وجدول فيديوهات محجوز للخطوة التالية.
- عملية تأكيد الطلب وتغيير المخزون تتم في معاملة واحدة، مع قفل صف النسخة لمنع تعارض التعديلات بين خوادم متعددة.
- قراءة المتجر لا تجلب بيانات العملاء، وتعرض المنتجات المتاحة فقط.
- اسم القاعدة وسر الاتصال لا يُرسلان للمتصفح؛ الاستعلامات تستخدم معاملات منفصلة عن النصوص المدخلة.

## ما يلزم قبل الإطلاق العام؟

الصور المرفوعة ما زالت على قرص الخادم المحلي. يجب نقلها إلى Supabase Storage أو تخزين كائنات دائم، وتعديل مسار الرفع والعرض، وتجربة الاستعادة. قاعدة البيانات لا تحفظ الملفات نفسها. كذلك دخول الإدارة الحالي بكلمة مرور واحدة مخصص للمعاينة؛ ننتقل إلى حسابات إدارية بصلاحيات واضحة قبل الإطلاق. تُراجع سياسات النسخ الاحتياطي وقنوات إشعار صاحب المزرعة قبل تفعيل الطلبات للعملاء.
