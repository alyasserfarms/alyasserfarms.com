# اتجاه لوحة إدارة مزارع آل ياسر

اللوحة أداة عمل لصاحب المزرعة: ما الطلب الذي يحتاج اتصالًا الآن؟ ما المنتج الذي يقترب من حد التوفر؟ وما المحصول الذي يجري التحضير له؟ لا تعرض أرقامًا استعراضية بلا مصدر.

## متاح الآن

- ملخص حي من قاعدة البيانات للطلبات والمخزون، مع تنقل مباشر للإجراء.
- إدارة المنتجات والتوفر والطلبات والإعدادات، مع تصفية الطلبات.
- شاشة أسعار مستقلة لتعديل السعر مباشرة وسجل دائم في قاعدة البيانات للسعر السابق والجديد والتوقيت. الطلبات القديمة تحتفظ بالسعر الملتقط لحظة إرسالها. حساب الإدارة ما زال مشتركًا، لذلك لا يُنسب التعديل إلى شخص بعينه.
- مركز طلبات يفرز ما يحتاج اتصالًا، وما هو قيد العمل، وما انتهى. لكل طلب رسوم توصيل، موعد متوقع، مسؤول وملاحظات داخلية محفوظة في قاعدة البيانات. تأكيد الطلب يتطلب تسجيل رسوم التوصيل ولو كانت صفرًا؛ والخروج للتوصيل يتطلب الموعد والمسؤول. الإجمالي النهائي يجمع المنتجات ورسوم التوصيل، بينما سعر المنتجات نفسه ثابت حسب لحظة إرسال الطلب.
- خطط محاصيل مستقلة عن مخزون البيع: اسم، قطعة، فدان، مواعيد، كمية متوقعة، حالة وملاحظات.
- مختبر تخطيط تجريبي في `/admin/planning-lab`: مشهد WebGL ثلاثي الأبعاد تفاعلي يوضح أشكال المحاصيل، مخطط مسطح بديل، ١٦ خيارًا مقسمة إلى حقول وخضروات وأشجار، وقطع افتراضية يمكن تعديلها. مجموعات الأغنام والسجلات الفردية تبقى ضمن العدد الإجمالي. يحفظ التجربة في المتصفح فقط ولا يكتب إلى قاعدة المزرعة. الأمثلة والاقتراحات البصرية ليست توصيات زراعية أو حدود أرض فعلية.
- عدّ زيارات مجهول يبدأ من الآن: متصفحات تقريبية يومية وصفحات شوهدت أسبوعيًا، لا أشخاص مؤكدون.
- إشارات منتجات غير معروضة سبق طلبها، حين يوجد سجل طلبات كافٍ.

## المرحلة التالية

1. استبدال كلمة المرور المشتركة بحسابات مسؤولي Supabase Auth وصلاحيات محددة وتسجيل أحداث التعديل. HTTPS وCookie آمنة قبل النشر العام.
2. نقل صور المنتجات إلى Supabase Storage حتى لا تضيع مع إعادة نشر الموقع.
3. إدارة فيديوهات YouTube والعروض الموسمية والمحتوى، مع حالات مسودة ونشر ومعاينة قبل العرض.
4. سجل عمليات للمخزون، وتكاليف ومدخلات ونتائج فعلية لخطط المحاصيل، ثم تقارير مرتبطة بهذه البيانات. لا يُحسب عائد أو ربح دون تسجيل التكاليف والبيع الحقيقي.
5. ربط تغيّرات الأسعار بهوية المسؤول بعد إتاحة حسابات مستقلة، ثم عرض تكلفة التوصيل الفعلية وربحية الطلب بعد توفر بيانات التكلفة. لا تُعرض أرباح تقديرية بلا مدخلات صحيحة.
6. تحسين قياس الزيارات بتصفية البوتات ومعايرة الأحداث؛ العداد الحالي مؤشر أولي فقط.

كل إضافة تعمل بالبيانات الفعلية، وتُراجع على الجوال والكمبيوتر قبل اعتمادها.
