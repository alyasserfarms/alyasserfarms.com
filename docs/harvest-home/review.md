# مراجعة امتداد هوية The Living Farm

التاريخ: 2026-10-29. النطاق: الأقسام التالية للهيرو في الصفحة الرئيسية. احتُفظ بالهيرو والهيدر المعتمدين والشعار الأصلي وCairo ولوحة الألوان.

## التكوين

- تعريف المزارع بتكوين صورتين متداخلتين ونخيل مصري تمثيلي مرخص.
- فهرس للفئات الست: صور ظاهرة متدرجة، ثلاث أعمدة للكمبيوتر وعمودان للجوال، مع تصفية فعلية للمنتجات.
- معرض منتجات بصري متفاوت الأحجام، وأزرار إضافة وتفاصيل وأسعار تجريبية واضحة.
- مشهد قصصي مثبت طبيعيًا، يتحول من الحقل إلى المحصول ثم يعود عند الصعود.
- قسم موسم على أرض عاجية وصورة قوسية وتفصيل فوتوغرافي متداخل.
- مشغل فيديو عند الطلب، لا يحمّل ملفه قبل النقر.
- ثلاث خطوات للطلب مع خط تقدّم قابل للعكس، ثم دعوة للمتجر وتذييل أخضر.

GSAP الموجود يدير مشاهد التمرير؛ لم تُضف مكتبات أخرى دون حاجة. الدخول يعاد عند الرجوع إلى الأقسام. النسخة دون JavaScript تحتفظ بالمحتوى، وتقليل الحركة يلغي التحولات والفيديو التلقائي. بقيت قنوات التواصل والأسعار والتوصيل والصور مصنفة للمعاينة دون اختراع بيانات معتمدة.

## التحقق

- نجح build وTypeScript وESLint.
- `scripts/check-harvest-home.mjs`: 78 فحصًا، RTL، الصور، وعدم الانزلاق الأفقي في الأقسام عند 320/390/768/1440، والتصفية وإعادة ضبطها وتفاصيل المنتج والإضافة والسلة والفيديو وحركة الموسم في الاتجاهين وتقليل الحركة.
- `scripts/check-reference-hero.mjs`: 45 فحصًا ناجحًا للهيرو والهيدر.
- صور الجوال والكمبيوتر في هذا المجلد؛ روجعت بصريًا أقسام التعريف والفئات والمنتجات والقصة والموسم والفيديو والطلب والتذييل.
- لا استثناءات JavaScript غير معالجة في الاختبارات. ليست هذه المراجعة شهادة وصول كاملة أو قياسًا لـCore Web Vitals.
- تباين أزواج الألوان الصلبة: الأخضر الأساسي/العاجي 11.08:1، الأصفر/الأخضر 6.65:1، النص الفاتح/الأخضر 9.65:1. الأخضر الطبيعي/العاجي 3.72:1 مستخدم للعناوين الكبيرة والزخارف، وليس للنصوص الصغيرة. هذه حسابات للرموز الصلبة وليست قياسًا لكل إطار فيديو.
