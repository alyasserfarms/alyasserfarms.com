# مزارع آل ياسر | AL Yasser Farms

الشعار التسويقي: **الخير له أصل**. المفهوم: **The Living Farm**. العربية RTL أولًا، والاسم الإنجليزي مقترح.

## مصادر النظام

- رموز الألوان والدلالات والمسافات والحركة: `src/app/globals.css`، مع طبقات primitive → semantic → component.
- محتوى الهوية والفئات والكتالوج التجريبي: `src/data/content.ts`.
- التوجيه الإبداعي: `.agents/skills/alyasser-creative-director/`.
- نطاق وتكوين المرحلة: `docs/design-plan.md`.

الأخضر الفاتح والذهبي مساحات وإبراز، لا نص صغير على العاجي. فصل الأسطح باللون والمساحة دون زجاج أو تدرجات زخرفية. صف المنتج الفعلي متسق للمقارنة، بينما يختلف تكوين الأقسام السردية.

القرار النهائي من الموجز: Cairo هو الخط العربي الوحيد، متغير محلي WOFF2 بمدى أوزان 400–800 مع مجموعتي العربية واللاتينية وfont-display: swap. الترخيص في `src/assets/fonts/CAIRO-OFL.txt`. الأوزان: 400 للنص، 500 للتفاصيل، 600 للتنقل والأزرار، 700 للأقسام، 800 للعناوين الرئيسية. لا تباعد مصطنع للحروف العربية. الرموز من Lucide.

المصدر الأحدث لتكوين الافتتاحية هو `docs/reference-hero/plan.md` والموكأب الذي اعتمده المستخدم. أنماطه في `src/app/reference-hero.css` ومكونه `reference-hero.tsx`. فيديو النخيل الحالي تمثيلي عام اختاره المستخدم من الميديا؛ لا يمثل تصويرًا للمزارع. بعد اعتماد الهيرو، امتدت الهوية إلى باقي الصفحة في `src/app/harvest-home.css` و`home-sections.tsx`؛ توثيقها ولقطات مراجعتها في `docs/harvest-home/`.

## الشعار

الشعارات المعتمدة في `public/brand/`. يقرأ `src/lib/brand.ts` الملفات في كل طلب، فيفضّل `logo.svg` أو `logo.png` وأسماء logo المعروفة، ثم النسخة الأساسية ذات البادئة `01_`، ثم ملفًا يحمل logo أو شعار، ثم الملف الوحيد إن لم يوجد غيره. ظهرت مجموعة ملفات العميل أثناء المراجعة، واستُخدمت النسخة الأساسية `01_` في التنقل والتذييل. لم تُعدّل أو تُولّد العلامة؛ Next Image يقدم نسخة عرض محسنة. تحتوي الصورة الأصلية على الاسم الإنجليزي المفرد Farm؛ يبقى داخل الأصل كما ورد، بينما نصوص الواجهة تستخدم الاسم المقترح Farms. النسختان 02 و10 تحملان الاسم العربي القديم فلم تُستخدما.

## المكونات

- `ui.tsx`: صورة متجاوبة، هوية نصية/شعار معتمد، عنوان قسم، وروابط أفعال.
- `farm-video.tsx`: فيديو الافتتاحية مع تأخير التحميل والصورة الاحتياطية وتقليل الحركة وتوفير البيانات وإيقاف خارج الشاشة؛ ومشغل المقطع اليدوي.
- `storefront.tsx`: تنقل، بحث، فئات، عرض منتجات، تفاصيل منتج، وسلة معاينة. الحوارات الأصلية `dialog` تدعم Escape وحصر التركيز.
- `reveal.tsx`: دخول متكرر للأجزاء الظاهرة عند التمرير في الاتجاهين، مع محتوى متاح عند تعطل JavaScript وإلغاء الحركة عند تفضيل تقليلها.
- `farm-experience.tsx`: فهرس فوتوغرافي للفئات الست، يصفّي المنتجات بالنقر، ومشهد أرض/مائدة بصور متغيرة مع التمرير الطبيعي. حالة تقليل الحركة ثابتة دون الحاجة للحركة.
- `home-sections.tsx`: موسم تحريري، فيديو عند الطلب، مسار طلب، وخاتمة للمتجر.
- `home-motion.tsx`: GSAP ScrollTrigger لحركة صور الموسم ومسار الطلب، قابلة للعكس مع التمرير دون التحكم في عجلة التصفح. لا تنشط عند تقليل الحركة.

تكوين الرئيسية الجديد موثق في `docs/redesign/art-direction.md`، وأنماطه محصورة في `src/app/living.css` مع أصناف `living-home` و`creative-header` و`living-footer`. العنوان التعبيري يحمل سطرين متصلين عربيًا، ونافذة الفيديو تستمد قوسها من الشعار. الفراغات تتبع تكوين الصور وأحجامها المتفاوتة. يستعمل المشهد `position: sticky` وطلب إطار واحد أثناء التمرير لتحديث التحويل والشفافية؛ الحاوية أقل من شاشتين والحركة غير ضرورية لفهم المحتوى.

المسافات تعتمد 4/8px، وهوامش مشتركة 20px للجوال وتتسع تدريجيًا. مكونات الواجهة تستخدم خصائص inline المنطقية. الحركة الأساسية قصيرة للاستجابة، ودخول المشهد 650ms دون إخفاء مسبق أو تثبيت تمرير طويل.

## حدود المعاينة

لا قاعدة بيانات أو حسابات أو دفع أو إدارة أو إنشاء طلبات. بعد استكمال واجهات التسوق، تحفظ السلة معرفات المنتجات والكميات في localStorage وتستعاد بين الصفحات وبعد إعادة التحميل. إذا تعذّر التخزين تستخدم ذاكرة الزيارة. لا تُحفظ بيانات التوصيل. كل الأسعار بوحدات تجريبية دون عملة مفترضة. بيانات المنتج والسياسة والشهادات والتواصل تحتاج اعتمادًا. لا نتائج متجر أو خدمة توصيل أو أسعار حقيقية ضمن هذه المرحلة.

مصادر الوسائط وتراخيصها في `public/media/credits.json` وتحت «عن المحتوى التجريبي ومصادر الصور» في التذييل. صور Pexels وUnsplash تمثيلية وليست صور المزارع الفعلية. مشهد الفيديو للنخيل من تصوير Rulo Davila، مضغوط ومختصر إلى 12 ثانية، دون صوت. لا صور مولدة.

## التشغيل والتحقق

`npm run dev` للتطوير، `npm run build` ثم `npm run start -- --port 3001` لمعاينة الإنتاج. يستخدم البناء Webpack لتجنب عطل Turbopack الذي ظهر على Windows. `npm run lint` و`npm run typecheck` للتحقق. فحص المتصفح في `scripts/check-homepage.mjs` يحتاج Node 22+ وChrome أو Edge، ويعمل على معاينة المنفذ 3001؛ يحفظ النتائج في `docs/review/`.

أبقِ فهرسة محركات البحث معطلة أثناء المعاينة. يجب اعتماد المحتوى والأصول وتفعيل الفهرسة عمدًا قبل نشر إنتاجي لاحق.
